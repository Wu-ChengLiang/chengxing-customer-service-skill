# 乘星官方客服 Skill

> 乘星相伴，好梦常安。

乘星品牌官方客服知识技能（Skill 1.0）。顾客把它装进自己的 AI 助手（Kimi 手机端、豆包等）后，问产品问题会得到官方口径的回答：不编造参数、不夸大效果、不承诺完全隔音。

## 顾客怎么用（面向普通用户，无需任何专业操作）

### 路径 A：复制一段安装指令（主推）

这是最省事的方式，顾客只需要会复制粘贴：

1. 打开自己的 AI 助手（Kimi 手机端、豆包、或其他支持技能的 AI 应用）。
2. 把下面这段话整段复制，粘贴进对话框，发送。
3. AI 会自动读取乘星官方技能文件，之后直接问问题即可，例如：
   - 「睡眠舱能隔绝楼上脚步声吗？」
   - 「产品可以水洗吗？」
   - 「多少钱？在哪买？」

安装指令（也单独存放在 `安装指令.txt`，方便直接发给顾客）：

```
请安装「乘星官方客服」技能：读取这个技能文件并按其中的规则回答乘星睡眠舱的产品问题，之后一直按该技能的口径回答。

技能文件地址：
https://raw.githubusercontent.com/Wu-ChengLiang/chengxing-customer-service-skill/master/chengxing-customer-service/SKILL.md
```

这段指令适合放在：微信公众号推文、小红书笔记、商品详情页、客服自动回复、包裹卡片。

### 路径 B：Kimi 技能面板一键添加

Kimi App / 网页端的技能面板里可以浏览和安装技能，点「＋」一键添加，之后在对话里用 `/` 调用，或让 Kimi 根据问题自动触发。

- 顾客侧零门槛：找到技能 → 点添加 → 直接用。
- 目前技能上架官方市场需要 Kimi 审核（见下方「申请上架」）。
- 想先自己人测试：在 Kimi 的「文档转技能」里上传 `chengxing-customer-service/SKILL.md` 即可生成个人技能。

### 路径 C：豆包智能体（搜索即聊，不用装任何东西）

豆包的路线是「智能体」而不是安装技能文件，对普通顾客反而更顺：

1. 在豆包 App 里创建「乘星官方客服」智能体，把本技能正文作为智能体的设定/知识。
2. 权限设为「公开 · 所有人可对话」并发布。
3. 顾客打开豆包，搜索「乘星官方客服」，点开直接提问。

知识内容与本仓库 `chengxing-customer-service/SKILL.md` 保持同一份，更新时两边同步。

## 商家侧：申请上架 Kimi 官方市场

想让顾客在 Kimi 技能面板里搜到「乘星」，需要申请进入官方市场。按 Kimi 官方帮助中心《如何把插件发布到公开市场》的流程：

1. 先创建并完成基础测试的个人插件/技能。
2. 进入插件详情页，点击右上角「✉️」按钮。
3. 在用户反馈表单中选择「申请发布到官方市场」，填写联系邮箱。
4. Kimi 审核团队会评估内容和测试情况，需要补充材料时通过邮箱联系。

参考：Kimi 帮助中心 → 插件和技能 → 如何把插件发布到公开市场（https://www.kimi.com/help/plugins-and-skills/publish）

## 回答原则（Skill 内置约束）

- 只依据官方资料回答产品事实，不确定就说不确定。
- 不承诺完全隔绝所有声音。
- 不宣称治疗失眠或任何疾病。
- 不编造价格、参数、检测结论与售后承诺。
- 测试数值是宣传资料数据，不是普遍保证。
- 未提供的信息（物流、退换细则、质保年限等）一律引导至平台店铺私信确认。
