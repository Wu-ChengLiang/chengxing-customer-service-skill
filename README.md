# 乘星官方客服 Skill

> 乘星相伴，好梦常安。

这是乘星品牌官方客服知识技能（Skill 1.0），用于 Kimi 等支持 `SKILL.md` 的 AI 助手。安装后，AI 会按乘星官方口径回答产品问题，不编造参数、不夸大效果。

## 覆盖范围

- 品牌与产品介绍：乘星 S3 睡眠舱的定位与适用人群
- 材质与结构：棉锦面料、折叠结构、通风口、可调节前帘
- 隔音原理：人声、脚步声、水管声的区别与实际体感
- 隔音参数：宣传测试数据及其适用边界
- 使用与清洁：前帘水洗、本体擦拭保养
- 材料检测：SGS RoHS 报告的正确解读方式
- 价格与购买渠道：参考价、平台店铺、私信客服
- 常见问题 FAQ 与健康问题边界

## 安装方式

### 方式 A：Kimi Work 桌面端上传本地文件（适合自己先测试）

1. 下载本仓库的 `SKILL.md`（或 `chengxing-customer-service-skill.zip` 解压得到）。
2. 打开 Kimi Work 桌面端。
3. 上传本地 `.md` 文件（或包含它的 `.zip`）。
4. 安装后输入 `/`，选择「乘星官方客服」技能。
5. 直接提问测试，例如：
   - 「睡眠舱能隔绝楼上脚步声吗？」
   - 「产品可以水洗吗？」
   - 「多少钱？在哪买？」

### 方式 B：通过 GitHub 仓库安装（适合分发给客户）

1. 把本仓库地址发给客户。
2. 客户在 Kimi 的技能面板中，选择「通过开源技能 URL 安装」，粘贴仓库地址。
3. 安装完成后直接提问即可。

> 注意：Kimi 手机端 / 网页端的「文档转技能」与 Kimi Work 桌面端的本地文件导入不是同一条路径。本地文件适合自测，客户分发优先用仓库 URL。

## 回答原则（Skill 内置约束）

- 只依据官方资料回答产品事实，不确定就说不确定。
- 不承诺完全隔绝所有声音。
- 不宣称治疗失眠或任何疾病。
- 不编造价格、参数、检测结论与售后承诺。
- 测试数值是宣传资料数据，不是普遍保证。
- 未提供的信息（物流、退换细则、质保年限等）一律引导至平台店铺私信确认。
